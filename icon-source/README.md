# App icon source (web + desktop)

The soluterminal mark is the website's pane layout: a near-black rounded tile
(`#0a0b0a`) holding three panes, a tall dim one on the left and two on the
right, the top-right one lime (`#d4ff3a`, "your move") over a dim one
(`#3b4139`). The site favicon, OG card, hosted sign-in and this app icon are
the same mark.

## Source of truth
`pane-mark.svg` is a verbatim copy of `website/src/favicon.svg`. If the site's
mark changes, copy it here and regenerate. `generate.js` reads the rects from
the SVG, so geometry and colours come from that one file. The one exception
is the hand-tuned 16/20/24/32 px layouts in `generate.js` (`SMALL`): at those
sizes the panes are placed on whole pixels with 2 px gaps, and at 16/20 px the
dim panes are lifted to `#56604f` so the layout still reads on a dark taskbar.

## Regenerate
Needs Node only (the PNG, ICO and ICNS encoders are built in):

```
node icon-source/generate.js
```

Writes:

| Output | Size(s) | Used by |
|---|---|---|
| `web/public/favicon.svg` | vector | browser tab favicon, manifest `any` |
| `web/public/icon-192.png` | 192 | favicon fallback, manifest `any`, notification icon/badge |
| `web/public/icon-512.png` | 512 | manifest `any` |
| `web/public/icon-maskable-192.png`, `icon-maskable-512.png` | 192, 512 | manifest `maskable` (opaque, panes inside the 80 % safe circle) |
| `web/public/apple-touch-icon.png` | 180 | iOS home screen (opaque; iOS rounds it) |
| `web/public/icon-mark-192.png` | 192 | in-app top bar mark |
| `desktop/src-tauri/icons/32x32.png` | 32 | Tauri `bundle.icon` (hand-tuned) |
| `desktop/src-tauri/icons/128x128.png` | 128 | Tauri `bundle.icon` |
| `desktop/src-tauri/icons/128x128@2x.png` | 256 | Tauri `bundle.icon` |
| `desktop/src-tauri/icons/icon.png` | 512 | Tauri `bundle.icon`, Linux/macOS window + tray icon |
| `desktop/src-tauri/icons/icon.ico` | 48 (first), 16, 20, 24, 32, 40, 64, 256 | Windows exe + NSIS installer resource; first entry is the window/taskbar icon |
| `desktop/src-tauri/icons/icon.icns` | 16–1024 | macOS dmg / dock |
| `desktop/src-tauri/icons/tray/tray-*.rgba` | 16, 20, 24, 32, 40, 48 | Windows tray, picked by system small-icon size (`src/tray_icon.rs`) |

## Shipping
`web/public/*` is the source; `web/dist`, `daemon/webdist` and `cloud/webdist`
are regenerated by `build.sh`/`publish.sh`. The service worker serves icons
stale-while-revalidate from its versioned cache, so bump `SW_VERSION` in
`web/src/sw.js` when the icons change. The exe, installer, taskbar and tray
icons are compiled into the Tauri shell, so they change with a shell rebuild.
Windows caches exe icons in its icon cache; an upgrade can show the old icon
until Explorer refreshes it.

# Contributing

Thanks for helping. Issues and pull requests are welcome.

## Before you start

- **Bugs:** open an issue with steps to reproduce, what you expected, and your
  OS and SoluTerminal version.
- **Changes:** for anything bigger than a small fix, open an issue first so we
  can agree on the approach.
- **Security problems:** don't open a public issue. Follow [SECURITY.md](SECURITY.md).

## Pull requests

- Keep each pull request to one change, and describe what it changes and why.
- Add or update tests for behaviour you change, and make sure CI passes.
- The build steps are in the [README](README.md#build-from-source).
